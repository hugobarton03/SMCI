# SMCI
This is a short analysis about my family´s enterprise.

This project is a brief analysis of the invoiced sales during the year 2023 and the first quartile of 2025 for my family's business. It features an interactive dashboard containing visualizations with key indicators to understand, first, the total sales amount invoiced per year. Then, a small insight reveals the top 5 clients during the period. Next, it displays the sales ticket per client based on year, quarter, or month. Finally, the analysis shows a cumulative sales total and percentage throughout the period.
The analysis helped uncover the total sales amount, whether annually, quarterly, or monthly. It also identified the main clients and how many sales were made to each of them.
This was carried out through the collection of billing data throughout the period, which was added to an Excel dataset for management and control. Later, the dataset was transferred to Power BI for the creation and handling of visualizations. Additionally, during this process in Power BI, new measures were created to obtain key indicators and achieve a more thorough analysis.
